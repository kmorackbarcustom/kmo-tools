## 🟡 สิ่งที่ Owner ต้องรับทราบ

- พนักงาน 5 คน / คนไทย / อายุ 18+ / ช่างทั้งหมด
- ลูกจ้างรายเดือน จ่ายสิ้นเดือน
- ทดลองงาน 119 วัน; ระบบเตือนก่อนครบ 14 วัน
- สัญญาจ้างไม่มีกำหนดระยะเวลา
- วันหยุดประจำสัปดาห์ = อังคาร
- วันหยุดตามประเพณี >= ขั้นต่ำกฎหมาย รวมวันแรงงานแห่งชาติ
- ลา/พักร้อน = ขั้นต่ำตามกฎหมาย ไม่มี KMO Extra โดยอัตโนมัติ
- Grace มาสาย 30 นาทีเป็นความผ่อนผัน ไม่เปลี่ยนเวลาเริ่มงาน
- ไม่มี clock-in + ไม่มี valid leave = ABSENT จนกว่าจะชี้แจง/ADMIN แก้
- ชี้แจง attendance ภายในวันทำงานถัดไป
- early clock-out = EARLY_LEAVE
- missing clock-out = MISSING_CLOCK_OUT
- พนักงานแก้ attendance เองไม่ได้
- Admin 2 คน (Owner + System Admin) สิทธิระบบเท่ากัน
- ไม่มีหัวหน้างานใน V1
- HR V1 ไม่เก็บจำนวนเงินเดือน
- LINE = employee identity
- Telegram = admin notification
- attendance ต้องอยู่ใน KMO geofence
- ไม่มีค่าปรับ/หักเงินอัตโนมัติ
- ความเสียหายลูกค้า/ร้านต้องสอบข้อเท็จจริงก่อน
- PPE ที่กำหนดต้องสวม; ไม่สวมให้หยุดงานเสี่ยงก่อน
- ห้ามใช้มือถือ/หูฟังระหว่างงานเสี่ยง
- ห้ามเมา/ยาเสพติดในการทำงาน
- ห้ามทะเลาะ ข่มขู่ คุกคาม ทำร้าย
- ห้ามนำรถลูกค้าออกขี่บนถนน
- งานส่วนตัวทำได้เมื่อ Owner อนุญาตและตกลงค่าใช้จ่าย
- ห้ามดึงลูกค้า KMO ไปรับเงินส่วนตัวโดยไม่ได้รับอนุญาต
- ข้อมูลลูกค้า/ความลับ KMO ห้ามนำไปใช้ส่วนตัว
- ทำ content/หารายได้เสริมได้ แต่ห้ามเปิดข้อมูลสำคัญและห้ามรบกวนความปลอดภัย
- ใช้ชื่อ/โลโก้ KMO แบบ official/sponsor ต้อง Owner อนุญาต
- เครื่องมือ/ทรัพย์สินออกนอกร้านต้อง Owner อนุญาต
- ลาออกต้องส่งมอบงาน/รถลูกค้า/ทรัพย์สิน/สิทธิระบบ แต่ห้ามใช้เป็นเหตุยึดค่าจ้างโดยมิชอบ
